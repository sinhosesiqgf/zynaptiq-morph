## Overview

Zynaptiq MORPH blends the spectral content of two audio sources in real time, creating hybrid sounds that seamlessly transition from one timbre to another.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Zynaptiq MORPH** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dual Input** | Two audio inputs are spectrally analyzed and morphed in real time |
| **Morph Knob** | Single knob smoothly transitions between source A and source B timbres |
| **Spectral Transfer** | Individual harmonic components of one source imposed on another |
| **Automation** | Automate the morph position for dynamic transitions in compositions |
